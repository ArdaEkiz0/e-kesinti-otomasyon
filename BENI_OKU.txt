📋 İÇERİK:
────────────────────────────────────────────────────────────────
✅ sgk_bot.py          → Ana bot dosyası
✅ KURULUM.exe         → OTOMATİK KURULUM (çift tıkla, hepsi kendiliğinden)
✅ BAT_BASLAT.bat      → Bot başlatma (kurulumdan sonra)
✅ çalışmaaaa.xlsx     → Excel veri dosyası (yoksa otomatik oluşturulur)
✅ BENI_OKU.txt        → Bu dosya (talimatlar)

🚀 KURULUM (YENİ BİLGİSAYARDA 1 KEZ):
────────────────────────────────────────────────────────────────

1. KURULUM.exe dosyasına ÇİFT TIKLA
2. Program otomatik olarak şunları yapar:
   ✅ Python kontrol → yoksa İNDİRİP KURAR
   ✅ Python sürümü kontrol → eskiyse yenisi kurulur
   ✅ Gerekli paketler (selenium, pandas, openpyxl, webdriver-manager)
   ✅ Google Chrome kontrol → yoksa İNDİRİP KURAR
   ✅ Chrome'a uygun chromedriver → yoksa İNDİRİR
   ✅ Excel şablonu (çalışmaaaa.xlsx) → yoksa OLUŞTURUR
3. "KURULUM TAMAMLANDI" yazısını görünce ENTER'a bas

⚠️  Python ilk kez kurulduysa bilgisayarı YENİDEN BAŞLAT.

📊 EXCEL ŞABLONU:
────────────────────────────────────────────────────────────────

çalışmaaaa.xlsx dosyası yoksa bot onu otomatik oluşturur.
Şablon yapısı hep aynıdır:

    Ünvan       | TC Kimlik No  | Matrah    | Bağ-Kur
    (İsim soyisim)| 11 haneli    | TL tutarı | Kesinti

Excel'e üretici bilgilerini doldur ve BAT_BASLAT.bat ile botu çalıştır.
(Matrah ve Bağ-Kur sütunlarındaki değerler sayı olmalıdır)

🚀 BOT BAŞLATMA (HER KULLANIMDA):
────────────────────────────────────────────────────────────────

   BAT_BASLAT.bat dosyasına çift tıkla

   1. Chrome tarayıcı açılır, SGK sitesine gider
   2. SİZ login yaparsınız (bot login yapmaz!)
   3. CMD'de ENTER'a basarsınız
   4. Bot tüm TC'leri otomatik işler ☕

📂 İSTEDİĞİN EXCEL DOSYASINI KULLANMA:
────────────────────────────────────────────────────────────────

   Bot artık klasördeki Excel dosyasını KENDİLİĞİNDEN bulur:

   1. Klasörde TEK Excel dosyası varsa → adı ne olursa olsun onu kullanır
      (çalışmaaaa.xlsx şart değil!)
   2. Birden fazla Excel dosyası varsa → sana seçtirir
      (örn. mayis.xlsx, haziran.xlsx arasından)
   3. Hiç Excel yoksa → şablon oluşturur

   İstersen dosyayı BAT_BASLAT.bat üzerine sürükleyerek de seçebilirsin.
   Not: Dosya içindeki sütun düzeni şablonla aynı olmalı
   (Ünvan, TC Kimlik No, Matrah, Bağ-Kur).

────────────────────────────────────────────────────────────────
